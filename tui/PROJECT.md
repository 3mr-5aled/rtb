# Project Metadata: devtui

- **Status**: Active
- **Created Date**: 2026-08-25
- **Tech Stack**: Rust, Ratatui, crossterm
- **Repository**: Local (D Drive)

## Description
Interactive terminal UI project manager built with Rust + Ratatui. Visual command center for the entire D drive development environment. Companion to the `dev` CLI PowerShell module.

## Local Setup
```powershell
cargo build --release -p rtbtui
```

## Usage
```
devtui          # Launch interactive TUI
```
Or via dev CLI:
```
dev ui          # (future integration)
```
