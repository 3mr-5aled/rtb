# Project Metadata: rtb-command-tool CLI

- **Status**: Active
- **Created Date**: 2026-08-25
- **Tech Stack**: PowerShell 7+
- **Repository**: Local (D Drive)

## Description

Unified developer project manager CLI for D drive. Consolidates project lifecycle management, health monitoring, and maintenance into a single `dev` command with full tab completion.

## Local Setup

- **Install**: Run `install.ps1` or add `Import-Module '<path-to-repo>\cli\rtb.psd1' -Force` to `$PROFILE`
- **Usage**: Type `rtb` or `dev` in any terminal
